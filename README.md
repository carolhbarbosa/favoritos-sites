Página web criada em HTML5 para guardar meus sites favoritos. Atividade da Agenda 12 do curso Técnico em Desenvolvimento de Sistemas.

## 📌 Sobre o projeto

A página reúne 5 sites que eu gosto de acessar. Para cada site, ela mostra:

- o nome do site, em destaque;
- o logotipo, com uma legenda de fonte;
- um link que abre o site em uma nova aba.

## 🛠️ Recursos de HTML utilizados

- Estrutura básica: `<!DOCTYPE html>`, `<html lang="pt-BR">`, `<head>` e `<body>`
- Título da aba com `<title>` e títulos com `<h1>`
- Imagens com `<img>` (atributos `src` e `alt`)
- Legendas com `<figure>` e `<figcaption>`
- Links com `<a>` (atributos `href` e `target="_blank"`)
- Comentários no código com `<!-- -->`

## ▶️ Como visualizar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no seu navegador.
